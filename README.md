# world1980 · 1980 冷战世界大战略模拟

从「1980 冷战地图查看器」进化为「1980 冷战大战略模拟游戏」的工程：等面积投影世界地图（Equal Earth），1980→1991 月度仿真，133 国 / 54 个可玩实体，事件驱动的历史剧本。

> 本仓库仅含**游戏本体**（`out/` 交付物 + `engine/` 仿真引擎 + `pipeline/` 地图管线）。完整开发文档、评审报告与内部任务书不在此仓库（源工程 `D:\Cline\world1980` 的 `docs/`、`HANDOFF.md`）。

## 快速开始（零依赖、断网可玩）

1. 双击 `out/打开地图.bat`（Windows）——起本地服务并自动打开浏览器。
2. 或手动：

```powershell
python out\serve.py --no-browser   # 起服务（端口 8815+，日志有 URL）
```

## 目录

| 目录 | 内容 |
|---|---|
| `out/` | 交付物：`index.html` + `app.js` + `style.css` + `data/` + `serve.py` + `打开地图.bat` |
| `engine/` | M4 仿真引擎（纯逻辑 JS，可脱离浏览器单测：`node engine/test_sim.js`，exit 0 = 门槛全过） |
| `pipeline/` | 地图构建管线（Python：s2→s6 生成 + s8 验收 + s9 回归） |

## 玩法速览

- 5 种地图模式：政治 / 阵营 / 人口 / 工业 / 政区（数字键 1–5 或 M 切换）
- 时间控制：▶ 播放 / 1×·2×·4× 倍速 / ↺ 重置（空格 = 播放/暂停）
- 点国家看面板：人口 / GDP / 工业 / 人均 / 面积（含「较 1980 ±X%」）
- 顶栏：存档 / 读档（localStorage）/ 导出 PNG / 搜索 / 帮助
- URL 钩子：`?m=` 模式 · `?c=` 国家 · `?t=YYYY-MM` 快进 · `?play=1` 自动播放 · `?simoff` 禁用仿真

## 仿真引擎（`engine/sim.js`）

- 纯逻辑、无 DOM：133 成员 ×（人口、产出指数）月度 tick，mulberry32 确定性随机
- 事件层：7 个历史事件（两伊战争 / 债务危机 / 油价崩盘 / 苏联改革 / 东欧剧变 / 海湾战争 / 苏联解体）
- 单测：`node engine/test_sim.js`（读真实交付数据，验证确定性 / 算术自洽 / 日期推进 / 性能）
